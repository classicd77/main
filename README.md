# LeadFlow CRM

מערכת CRM לניהול לידים של יועצי השקעות. היא רצה כולה בדפדפן, בלי שרת ובלי שלב build, ומתפרסת כמו שהיא ל-Azure Static Web Apps (דרך ה-workflow הקיים).

## מה יש במערכת

| אזור | מה אפשר לעשות |
|---|---|
| **דשבורד** | כרטיס שווי הצנרת, מדדי KPI עם ספארקליינים, מגמת לידים, פילוח סטטוסים, משפך המרה, מעקבים, פעילות אחרונה. כל רכיב אפשר להוסיף או להסיר ("הוספה / הסרה של רכיבים", או ✕ על הרכיב). |
| **לידים** | טבלה עם חיפוש, סינון (סטטוס, תיק, מקור, מטרה, טווח) ומיון, וגם פעולות מרובות: שינוי סטטוס, תיוק, מייל קבוצתי, ייצוא, ארכיון ומחיקה. |
| **כרטיס לקוח** | שם פרטי, שם משפחה, עיר, נייד, אימייל, גיל, מקצוע, טווח השקעה, מטרת ההשקעה, סכום, דמי ניהול מוצעים, הכנסה שנתית צפויה ופירוט השיחה. יש בו גם שלבי סטטוס, ציון ליד, תגיות, חיוג, וואטסאפ, מייל ויומן פעילות. |
| **צנרת מכירות** | לוח קנבן שבו גוררים כרטיס כדי לשנות סטטוס. |
| **מעקב ותזכורות** | המעקבים מחולקים לבאיחור, היום, השבוע ובהמשך. אפשר לסמן מעקב כבוצע או לדחות אותו ב-1, 3 או 7 ימים. |
| **קליטה ממייל** | סנכרון אוטומטי מכתובת המייל שמוגדרת בהגדרות, הדבקה של תוכן מייל, או גרירה של קבצי `.eml`. המערכת מזהה את השדות לבד (בעברית ובאנגלית) ומתריעה על כפילויות. |
| **מיילים** | שליחה מתבניות עם משתנים (`{{שם פרטי}}`, `{{סכום}}`…), מייל קבוצתי, צירוף קבצים שיווקיים ויומן של המיילים שנשלחו. |
| **קבצים שיווקיים** | העלאה של מצגות, תמציות מנהלים, ברושורים ועוד, לפי קטגוריות. אפשר לצפות בקובץ, להוריד אותו ולשלוח אותו במייל. |
| **דוחות** | בחירת טווח תאריכים ותיק, ופילוחים לפי סטטוס, מטרה, טווח, גיל, גודל השקעה, עיר, מקור ומקצוע. הייצוא הוא ל-CSV (נפתח בעברית תקינה באקסל) או להדפסה / PDF. |
| **תיוק** | תיקים בצבעים (בסרגל הצד) וארכיון. |

## קליטה ושליחה אוטומטית של מיילים

אתר סטטי לא יכול לגשת לבד לתיבת דואר. לכן המערכת משתמשת ב"גשר Gmail": סקריפט Google Apps Script חינמי שרץ בחשבון הגוגל שלכם. הקוד שלו מופיע ב**הגדרות ← מייל וקליטת לידים**, יחד עם הוראות הפריסה (כ-2 דקות). אחרי החיבור המערכת:

- מושכת מיילים חדשים מהכתובת שהגדרתם (אפשר גם לסנן לפי נושא), ידנית או אוטומטית כל X דקות;
- שולחת מיילים ישירות מה-Gmail שלכם, כולל קבצים מצורפים.

בלי הגשר אפשר לשלוח מיילים דרך תוכנת הדואר במחשב או דרך חלון כתיבה ב-Gmail. כדי לקלוט לידים בלי הגשר, מדביקים את תוכן המייל או גוררים קובץ `.eml`.

## איפה הנתונים נשמרים

הלידים וההגדרות נשמרים ב-`localStorage`, והקבצים ב-IndexedDB של הדפדפן. הנתונים לא יוצאים מהמחשב, אבל הם גם לא מסתנכרנים בין מחשבים. **הגדרות ← נתונים וגיבוי** מאפשר להוריד גיבוי JSON מלא (כולל קבצים) ולשחזר ממנו. שם אפשר גם לטעון נתוני הדגמה.

## הרצה מקומית

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

(צריך שרת כי הקוד בנוי מ-ES modules. פתיחה ישירה של הקובץ לא תעבוד.)

## מבנה

```
index.html          מעטפת האפליקציה
css/styles.css      עיצוב (מצב בהיר/כהה, RTL, רספונסיבי, הדפסה)
js/app.js           ניתוב, סרגל צד, חיפוש גלובלי, ערכת נושא, סנכרון אוטומטי
js/store.js         מודל הנתונים, שמירה, IndexedDB, נתוני הדגמה
js/parser.js        זיהוי שדות ליד ממייל, פענוח ‎.eml‎ (MIME)
js/mailer.js        גשר Gmail (קוד ה-Apps Script), שליחת מיילים
js/charts.js        גרפים ב-SVG עם tooltip
js/metrics.js       חישובים לדשבורד ולדוחות
js/components.js    טופס ליד, חלון כתיבת מייל, תגיות
js/views/*.js       המסכים
```

קיצורי מקלדת: `/` לחיפוש, `n` לליד חדש.
